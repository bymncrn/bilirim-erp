# Bilirim POS Display

Manav ve şarküteriler için şık, modern bir kasa satış ekranı tasarımı yap. En üstte 'Bilirim POS' başlığı olsun. Sol tarafta hızlı ürün seçimi için renkli kartlar (Elma, Domates, Kaju, Peynir), sağ tarafta ise anlık sepet/adisyon listesi ve 'Ödeme Al' butonu yer alsın
